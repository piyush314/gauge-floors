# Security policy

This repository is a research artifact and is not maintained as a production
security boundary. The `main` branch is the only supported version.

Do not disclose a suspected credential, privacy issue, dependency compromise,
or exploitable code-execution problem in a public issue. Use GitHub's private
vulnerability-reporting interface when available, or email `saopk@ornl.gov`
with the subject `gauge-floors security report`. Include affected paths,
reproduction steps, and impact. Please do not include real secrets or personal
data in a proof of concept.
